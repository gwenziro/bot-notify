4

Dokumentasi Lengkap

Kirim Pesan Personal

Contoh Request API 
curl -X POST "{{.BaseURL}}/api/send/personal" \
  -H "X-Access-Token: {{.MaskedToken}}" \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "6281234567890",
    "message": "Ini adalah pesan notifikasi"
  }'

Kirim Pesan Grup

Contoh Request API 
curl -X POST "{{.BaseURL}}/api/send/group" \
  -H "X-Access-Token: {{.MaskedToken}}" \
  -H "Content-Type: application/json" \
  -d '{
    "groupId": "120363144182570365@g.us",
    "message": "Ini adalah pesan grup"
  }'

Broadcast Pesan

Contoh Request API 
curl -X POST "{{.BaseURL}}/api/send/broadcast" \
  -H "X-Access-Token: {{.MaskedToken}}" \
  -H "Content-Type: application/json" \
  -d '{
    "personalNumbers": ["628123456789", "628987654321"],
    "groupIds": ["120363144182570365@g.us"],
    "message": "Ini adalah pesan broadcast",
    "delayMs": 1000
  }'
