Dokumentasi API Bot Notify

Bot Notify API memungkinkan Anda mengirimkan pesan WhatsApp secara programatis. API ini RESTful dan menggunakan format JSON untuk permintaan dan respons.

Base URL
{{.BaseURL}}
Format
JSON
Version
v1.0.0

Autentikasi

Semua permintaan API memerlukan token akses yang valid. Token dikirim melalui header HTTP X-Access-Token.

Contoh Autentikasi 
curl -X GET "{{.BaseURL}}/api/status" \
  -H "X-Access-Token: {{.MaskedToken}}"

Batasan Rate

API ini memiliki batasan rate untuk mencegah penyalahgunaan. Batas default adalah 60 permintaan per menit. Jika Anda melebihi batas, permintaan Anda akan ditolak dengan kode status HTTP 429 (Too Many Requests).

Info: Header respons menyertakan X-Rate-Limit-Remaining yang menunjukkan berapa banyak permintaan tersisa dalam jendela waktu saat ini.

Kode Error

Berikut adalah daftar kode error yang mungkin Anda temui saat menggunakan API.

Kode Status Deskripsi
400 Bad Request Permintaan tidak valid atau parameter yang diperlukan hilang
401 Unauthorized Token akses tidak valid atau kedaluwarsa
403 Forbidden Token valid tetapi tidak memiliki izin yang cukup
404 Not Found Endpoint atau sumber daya yang diminta tidak ditemukan
429 Too Many Requests Melebihi batas rate API
500 Internal Server Error Terjadi kesalahan pada server
503 Service Unavailable Layanan WhatsApp tidak tersedia saat ini
